# Messaging and offer test protocol

Messaging and offer tests look cheap (change some words, change a price) and are easy to get wrong. They touch brand, legal, margin and sales teams at once. This protocol keeps them fast and safe.

## 1. Decide what you are testing

| Test type | Question | Primary metric | Mandatory guardrail |
|---|---|---|---|
| Value proposition | Which benefit makes the most people take the next step? | Click-through or checkout start | Lead-to-order rate |
| Proof and trust | Which proof reduces hesitation? | Checkout completion | Refund or cancellation rate |
| Offer framing | Does the same offer perform better framed differently? (e.g. "first 3 months half price" vs "save 60 in year one") | Order rate | Margin per order |
| Offer level | Does a richer offer pay for itself? | Orders x margin | M3 retention |
| Price presentation | Monthly vs total, with vs without reference price | Order rate | Contact-centre contacts about price |

Framing tests (same economics, different words) are cheap and should run first. Offer-level tests change economics and need finance sign-off.

## 2. Pre-test qualitative screen

Before spending traffic, screen five to eight message candidates quickly:

- Five-second test or preference test with 50 to 100 target respondents
- Comprehension check: can respondents say back what the offer is?
- Keep the two or three best for the live test. Never live-test more variants than your traffic can power.

## 3. Message match

The promise must be identical across ad, landing page, checkout and confirmation email. A test that changes the ad but not the page measures mismatch, not the message. List every touchpoint the variant appears in and change all of them.

## 4. Compliance and brand

- [ ] Claims are substantiated (speed, price, availability)
- [ ] Price shown includes everything required by local advertising rules (e.g. the price after any promotional period)
- [ ] Terms are linked from every variant
- [ ] Brand team has approved tone, not each word
- [ ] Sales and contact-centre teams briefed on every live variant so they can answer questions

## 5. Running

- Same audience, same placement, same time window for all variants
- Run full weeks
- For offer tests, cap exposure (for example 20% of traffic) until the first margin read

## 6. Judging the result

- Judge offer tests on **margin per visitor** or **margin per customer at M3**, not conversion alone
- Report the confidence interval of the lift, not just the winner
- If a framing wins, test it in a second channel before rolling out everywhere
- Add the winning message to the message library with the evidence attached, so it becomes the new control
